# Project Instructions

## Source of Truth

The implementation specification is:
`docs/implementation-spec.md`

The current project state is:
`docs/current-state.md`

Read both before making substantial architectural changes.

## Development Rules

- Follow the implementation specification.
- Work on one milestone at a time.
- Do not implement future milestones without explicit approval.
- V1 contains no AI or LLM functionality.
- Prefer deterministic implementations.
- Do not introduce unnecessary infrastructure.
- Do not add dependencies without justification.
- Preserve existing working functionality.
- Never commit secrets or personal information.
- Update `docs/current-state.md` after completing meaningful milestone work.

## Agent Behavior

Before implementing a substantial task:
1. Inspect the existing repository.
2. Determine the current milestone and state.
3. Explain the proposed approach.
4. Identify important risks or ambiguities.
5. Implement only the requested scope.
6. Test the result.
7. Record the verified state.
